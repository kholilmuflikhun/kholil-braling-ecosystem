# Security Baseline

- Validate all inputs on the server.
- Enforce authorization on every protected server action and route.
- Keep secrets server-side and out of source control.
- Verify payment webhook signatures and process events idempotently.
- Restrict customer access to their own records.
- Validate file type, size, and access permissions.
- Use audit logs for sensitive business and financial actions.
- Never trust client-submitted prices, totals, stock quantities, or payment states.
